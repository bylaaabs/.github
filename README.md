# `.github` for [bylaaabs](https://github.com/bylaaabs)

This repository holds the **organisation defaults** for the [laaabs.](https://laaabs.com) GitHub org.

## What's here

| Path | Purpose |
|---|---|
| `profile/README.md` | The public profile shown at [github.com/bylaaabs](https://github.com/bylaaabs). |
| `CODE_OF_CONDUCT.md` | Default Code of Conduct. Inherited by repos without their own. |
| `SECURITY.md` | Default security policy. Inherited by repos without their own. |
| `.github/FUNDING.yml` | Sponsor button (`aaangelmartin` on GitHub Sponsors) for every repo. |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default PR template. Inherited. |
| `.github/ISSUE_TEMPLATE/` | Default issue templates. Inherited. |

## Visibility

This repo is **public** so the profile renders on the org page. The community defaults inside (CoC, SECURITY, etc.) propagate to **both public and private** repos automatically.

## Standards

Per-product overrides live in each product's repo. Studio-wide standards are in [`bylaaabs/handbook`](https://github.com/bylaaabs/handbook).
